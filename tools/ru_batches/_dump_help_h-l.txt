##### import_csv
help.import_csv.content = "CSV import turns a spreadsheet into scheduled messages — perfect for content plans prepared in Excel or Google Sheets.\n\n<b>The format</b>\nThe file needs two columns: <code>Date/Time</code> and <code>Content</code>. Export your sheet as CSV (UTF-8) and send it to the bot during the import flow. Each row becomes one scheduled message; the date column accepts the same formats the bot accepts when typing (for example <code>25.12.2025 10:00</code>).\n\n<b>Where messages land</b>\nRows are imported into your connected channel — the import targets it directly, there is no channel picker. Times are interpreted in the channel's time zone.\n\n<b>Tips for clean imports</b>\n• Keep one message per row; put line breaks inside the Content cell.\n• Test with a two-row file first, review the result in the Message List, then import the full sheet.\n• Need richer structure (multiple channels, media)? Use <code>.txt</code> blocks or a full backup restore instead."
help.import_csv.title = "CSV Import"
