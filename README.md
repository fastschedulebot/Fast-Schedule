# Fast Scheduler for Telegram

Fast Scheduler is a Telegram bot for scheduling and managing posts in Telegram channels.

<p align="center">
  <a href="https://t.me/FastSchedulerBot"><strong>▶ Try @FastSchedulerBot</strong></a>
</p>

## What makes it special

You can create several scheduled messages in one conversation. Send date/message pairs in one message:

```text
2026-12-24 18:00
First holiday message

2026-12-25 12:00
Second holiday message

2026-12-31 23:00
New Year message
```

The bot reads each date and time together with the content that follows it and creates the scheduled messages at once. The bot shows the supported date and time formats during the scheduling flow.

## Features

- Schedule one-time Telegram channel posts.
- Create multiple scheduled posts from one message.
- Use a user or channel timezone.
- Create recurring posts with built-in schedules or custom cron expressions.
- Preserve supported Telegram formatting and captions.
- Schedule text, photos, videos, documents, animations, audio, voice messages, polls, locations, and other supported Telegram content.
- Choose media handling for a batch:
  - reuse one media item;
  - assign media sequentially;
  - choose media randomly;
  - select media from Media Storage.
- Add reusable signatures automatically at the beginning or end of posts.
- View scheduled and recurring messages in lists and the calendar.
- Search, preview, edit, delete, duplicate, replace, and manage supported messages.
- Connect Telegram channels and optionally publish through a separate sender bot.
- Save reusable Telegram media references in Media Storage.
- Export and back up supported account data.
- View available sending statistics and channel analytics.
- Use Premium through Telegram Stars when Premium purchases are enabled.

Available limits and actions depend on the current plan, Telegram permissions, Telegram API restrictions, and the message type.

## Quick start

1. Open [@FastSchedulerBot](https://t.me/FastSchedulerBot).
2. Complete the built-in tutorial.
3. Add the bot as a channel administrator with at least **Post Messages** permission.
4. Connect the channel in the bot.
5. Optionally connect a sender bot and add it as an administrator in the same channel.
6. Set your timezone.
7. Create a scheduled or recurring post.

# Fast Scheduler для Telegram

Fast Scheduler — это Telegram-бот для планирования и управления публикациями в Telegram-каналах.

<p align="center">
  <a href="https://t.me/FastSchedulerBot"><strong>▶ Попробовать @FastSchedulerBot</strong></a>
</p>

## Что делает бот особенным

Можно создать несколько запланированных публикаций в одном диалоге. Отправьте пары «дата/время + сообщение» одним сообщением:

```text
2026-12-24 18:00
Первое праздничное сообщение

2026-12-25 12:00
Второе праздничное сообщение

2026-12-31 23:00
Новогоднее сообщение
```

Бот связывает каждую дату и время со следующим содержимым и создаёт все запланированные публикации сразу. Поддерживаемые форматы даты и времени бот показывает во время планирования.

## Возможности

- Планирование разовых публикаций в Telegram-канал.
- Создание нескольких публикаций одним сообщением.
- Использование часового пояса пользователя или канала.
- Повторяющиеся публикации по готовому расписанию или через cron.
- Сохранение поддерживаемого Telegram форматирования и подписей к медиа.
- Планирование текста, фотографий, видео, документов, анимаций, аудио, голосовых сообщений, опросов, геопозиций и других поддерживаемых типов Telegram.
- Режимы медиа для пакетной публикации:
  - использование одного медиа;
  - назначение медиа по порядку;
  - случайный выбор медиа;
  - выбор из Media Storage.
- Автоматические подписи в начале или конце публикаций.
- Списки и календарь запланированных и повторяющихся сообщений.
- Поиск, предпросмотр, редактирование, удаление, дублирование, замена и другие доступные действия.
- Подключение каналов и публикация через отдельный sender bot.
- Сохранение повторно используемых Telegram media в Media Storage.
- Экспорт и резервное копирование поддерживаемых данных.
- Доступная боту статистика отправок и аналитика каналов.
- Premium через Telegram Stars, если покупки Premium включены.

Доступные лимиты и действия зависят от текущего тарифа, прав Telegram, ограничений Telegram API и типа сообщения.

## Быстрый старт

1. Откройте [@FastSchedulerBot](https://t.me/FastSchedulerBot).
2. Пройдите встроенный tutorial.
3. Добавьте бота администратором канала минимум с правом **Post Messages**.
4. Подключите канал в боте.
5. При необходимости подключите sender bot и добавьте его администратором в тот же канал.
6. Укажите часовой пояс.
7. Создайте разовую или повторяющуюся публикацию.
